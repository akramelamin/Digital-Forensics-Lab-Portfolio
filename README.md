# 🔬 Digital Forensics & Incident Response (DFIR) Lab Portfolio

Welcome to my DFIR portfolio. This repository contains hands-on forensic investigations, malware artifact analysis, memory dumps analysis, network traffic analysis, and incident response documentation.

---

## 🛠️ Tools & Technologies
* **Disk & File Analysis:** Autopsy, FTK Imager, Eric Zimmerman Tools (EZ Tools)
* **Memory Forensics:** Volatility 3, DumpIt
* **Network Forensics:** Wireshark, Brim
* **OS Systems Tested:** Windows Server 2022, Windows 10/11, Kali Linux, Ubuntu

---

## 📂 Portfolio Structure

* **`01-Memory-Forensics/`** -> RAM analysis, process extraction, and malicious code detection.
* **`02-Disk-and-File-Analysis/`** -> File carving, partition analysis, and deleted file recovery.
* **`03-Network-Forensics/`** -> PCAP analysis, malicious IP tracking, and C2 communication identification.
* **`04-Windows-Artifacts-and-Registry/`** -> Prefetch analysis, Shellbags, LNK files, and Event Log investigation.
